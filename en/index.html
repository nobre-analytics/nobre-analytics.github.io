The same path in every case

From the first bot to the last panel. It is what makes the queue shrink instead of repeating the same mistake.

01

Origin

Find where the error is born, not where it shows up. The symptom is usually three systems away from the cause.

data source capture diagnosis screen

The R$ 326K hole was in the second box, and the alarm was expected in the fourth.

02

Rule

Write the rule in the language of the operation, using the names they already use.

03

Reproduce

Prove the rule on a real case before trusting it. A case that does not reproduce is not a rule yet.

04

Sweep

Run the rule across the whole queue, not only on the case that showed up. It is the difference between putting out fires and closing the tap.

Automation with no document becomes a black box

Every system ships with these four documents, kept next to the code and updated when the rule changes.

Product brief Audience, purpose, positioning, constraints and principles. One per system.
Process mapping The manual step by step before any automation, with the business rules made explicit.
Operator manual Written in the order the person works, not in the order the system runs.
Risk log What is fragile, why it is acceptable today and which condition makes it unacceptable. With a date and a reason.
